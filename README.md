# Scaffale Carte

Collezione di carte Magic: The Gathering su scaffali, con consigli di mazzo per formato.

- Importa da `.txt` (`4 Lightning Bolt`) o dall'export CSV di ManaBox
- Immagini e dati da [Scryfall](https://scryfall.com) (serve internet)
- Mazzi meta confrontati con la tua collezione + mazzi costruiti con le tue carte
- Tutto resta nel browser (localStorage): nessun server, nessun account

Sito: abilita GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Immagini delle carte © Wizards of the Coast, fornite da Scryfall.
